On the inscription & its recovery

The shared Rust structural analyzer recognizes common declarations in nine languages. It is not a compiler or a complete runtime call graph: dynamic dispatch, macros, expression-bodied functions, complex generics, and uncommon syntax may remain unresolved. Calls connect when their targets are unambiguous.

GitHub input preserves every tracked file in the selected commit, including binary and unsupported files. New transmutations have one output: deterministic SVGZ. Ordinary rendered geometry is rounded only below visible-pixel scale before compression, while reversible name contours remain exact. The repository capsule remains byte-exact and, when keyed, authenticated and encrypted. Restore the canonical SVGZ to recover exact bytes, paths, modes, symlink targets, and submodule pointers. Legacy source-carrying PNG/SVG/SVGZ files remain importable for recovery and migration. Git history, external submodule contents, and expanded Git LFS objects are outside the tracked snapshot. Folder input excludes .git, target, node_modules, and pkg; browsers cannot read filesystem modes or symlinks. Limits: 5,000 files, 2 MB per file, 50 MB total.

Live light kindles each caller, follows its resolved call channels in lexical source order, awakens the destination, and traces returns back before the next call. Independent entry points may play together. Recursion is bounded to one visit per resolved channel in each rehearsal. This is a structural illustration: branches, loop counts, asynchronous scheduling, and runtime values are not executed or predicted. Glow and motion belong to the live display. Canonical exports are deterministic; visible geometry is perceptually compressed and source recovery is exact. Keyed images require their original key.
