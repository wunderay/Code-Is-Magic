On the inscription & its recovery

The shared Rust structural analyzer recognizes common declarations in nine languages. It is not a compiler or a complete runtime call graph: dynamic dispatch, macros, expression-bodied functions, complex generics, and uncommon syntax may remain unresolved. Calls connect when their targets are unambiguous.

New transmutations have one canonical format: a standards-compliant PNG whose visible RGB is deterministically coalesced by at most one 8-bit code value per channel before lossless PNG compression. The exact repository capsule is stored separately in a private ancillary PNG chunk, so compression no longer injects noisy source bits into the artwork. Recovery remains byte-exact for source paths, bytes, modes, symlink targets, and submodule pointers. Existing source-carrying PNG, SVG, and SVGZ files remain readable for backward compatibility.

Glow and motion belong to the live display. Canonical PNGs remain deterministic and recoverable. Keyed images require their original key. Generic editors that discard private PNG chunks can remove source recovery data, so preserve the original Code Is Magic PNG when exact recovery matters.
