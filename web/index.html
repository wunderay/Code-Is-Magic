What this diagram knows

This is a structural source-code visualization, not a compiler or a complete runtime call graph. The shared Rust lexer ignores strings and comments and recognizes common declarations in Rust, Python, JavaScript, TypeScript, Go, C, C++, Java, and C#. Dynamic dispatch, macros, expression-bodied functions, complex generics, and uncommon syntax may be unresolved. Calls connect when the target is unambiguous; external and ambiguous calls are counted separately.

GitHub input preserves every tracked file and visualizes supported source files in the selected commit, including vendored sources; submodules belong to separate repositories. Other extensions are reported in the read summary. Budget limits are 5,000 source files, 2 MB per file, and 50 MB total. A limit or download failure stops the request without displaying a partial diagram. Local folder mode excludes .git, target, and node_modules. All inscriptions use vector paths, with no text or filenames in the artwork. A visible radial contour losslessly encodes each qualified name. Exported PNGs preserve the full snapshot in RGB pixel bits; SVGs preserve it in a source capsule. Recover the original exported file to obtain a ZIP containing exact bytes, paths, executable modes, symlink targets, and submodule pointers. Git history, external submodule contents, and expanded Git LFS objects are not part of the parent commit's tracked file snapshot. JPEG conversion, resizing, cropping, screenshots, or other pixel edits can destroy the PNG capsule. GitHub input is complete for the selected tracked tree; browser folder input preserves selected file bytes but cannot read filesystem modes or symlinks.
